# 开发任务拆解

## 0. 决策确认

| 编号 | 任务 | 优先级 | 产出 |
| --- | --- | --- | --- |
| D0-1 | 确认后端独立服务还是并入现有后端 | P0 | 服务边界说明。 |
| D0-2 | 确认 PostgreSQL 实例和连接方式 | P0 | 数据库配置。 |
| D0-3 | 确认组件元数据初始化方式 | P0 | seed 或后台维护方案。 |
| D0-4 | 确认资源上传存储方式 | P1 | 本地、对象存储或现有文件服务方案。 |
| D0-5 | 确认测试/生产域名、端口、镜像仓库 | P1 | 部署参数清单。 |

## 1. 前端任务

| 编号 | 任务 | 优先级 | 验收 |
| --- | --- | --- | --- |
| FE-1 | 初始化 React + Vite + TypeScript + Ant Design | P0 | `npm run dev` 可启动。 |
| FE-2 | 接入 qiankun 生命周期和 basename | P0 | 独立运行和微前端挂载均可渲染。 |
| FE-3 | 实现 API client 和运行时配置 | P0 | 可从 `/env.js` 或 qiankun props 读取 API 地址。 |
| FE-4 | 实现首页模板列表 | P0 | 支持加载、空、错误、搜索、刷新。 |
| FE-5 | 实现编辑器基础布局 | P0 | 左侧组件、中间画布、右侧配置、顶部工具栏。 |
| FE-6 | 实现编辑器状态 store | P0 | 区分 `route_id`、`id`、`diy_id`。 |
| FE-7 | 实现单层组件添加、排序、选中、删除 | P0 | 页面内组件可编辑。 |
| FE-8 | 实现保存流程 | P0 | 保存成功后可再次打开一致。 |
| FE-9 | 实现动态 schema 表单基础字段 | P1 | 支持 text、number、color、switch、select。 |
| FE-10 | 实现上传、截图封面和复杂组件 | P2 | 图片和封面流程可用。 |

## 2. 后端任务

| 编号 | 任务 | 优先级 | 验收 |
| --- | --- | --- | --- |
| BE-1 | 初始化 FastAPI 分层结构 | P0 | `/health` 和 `/docs` 可访问。 |
| BE-2 | 实现统一响应和错误处理 | P0 | 成功/失败响应结构固定。 |
| BE-3 | 定义 Pydantic schema | P0 | 模板、页面、组件字段与 PRD 一致。 |
| BE-4 | 实现模板列表和详情接口 | P0 | 首页和编辑页可消费。 |
| BE-5 | 实现组件元数据接口 | P0 | 前端组件面板可消费。 |
| BE-6 | 实现页面保存接口 | P0 | create/edit/copy 基础流程可保存。 |
| BE-7 | 定义 SQLAlchemy 模型和 Alembic 迁移 | P1 | 可创建基础表。 |
| BE-8 | 实现 use/delete/assets 接口 | P1 | 首页操作闭环。 |
| BE-9 | 加入乐观锁、操作日志、schema 校验 | P1 | 冲突和审计可追踪。 |
| BE-10 | 增加 pytest 接口和服务测试 | P1 | 核心接口有测试覆盖。 |

## 3. 部署任务

| 编号 | 任务 | 优先级 | 验收 |
| --- | --- | --- | --- |
| OPS-1 | 编写前后端 Dockerfile | P0 | 镜像可构建。 |
| OPS-2 | 编写 docker-compose | P0 | 本地可一键启动。 |
| OPS-3 | 编写 Nginx 配置 | P0 | `/store_design/*` 和 API 代理可用。 |
| OPS-4 | 编写 CI workflow | P1 | push/PR 可执行 build/test。 |

| OPS-6 | 增加生产审批和回滚 | P2 | release/tag 可控发布。 |
